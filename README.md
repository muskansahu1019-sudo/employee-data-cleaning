# Employee Data Cleaning Project using Python Pandas

## Objective
This project focuses on cleaning a messy employee dataset using Python and Pandas to prepare the data for analysis.

## Tasks Performed
- Handled missing values in Age and Salary
- Removed duplicate records
- Converted Join_Date to datetime format
- Corrected Age data type
- Corrected Salary data type
- Cleaned and exported final dataset to CSV

## Tools Used
- Python
- Pandas
- CSV Dataset

## Files Included
- Messy_Employee_dataset.csv (Raw Dataset)
- employee_cleaned_data.csv (Cleaned Dataset)
- data_cleaning_project.py (Python Script)

## Key Learning
Through this project, I learned how to handle missing values, convert data types, remove duplicates, and debug data cleaning workflows using Pandas.
